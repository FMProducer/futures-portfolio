## Фиксированные бэктесты

Загружены 3 публичных месячных архива Binance USD-M за **01–30 сентября 2026**,
каждый — 43 200 минут. SHA256 сверены с опубликованными .CHECKSUM. Проверены
монотонность, уникальность, шаг 60000 ms, границы месяца и положительные цены.
URL/хеши — `market_data_manifest.json`; исходные ZIP/CSV/Feather сохранены в
локальном `market_data/`, не добавляются в Git. Скрипт fetch_data.py восстанавливает
входы по URL и сверяет checksum; для долгосрочной воспроизводимости хранить ZIP.

Параметры не оптимизировались: config.json исходного HEAD, капитал 14 USDT,
LONG/SHORT 50/50 по 7x; commission=0.0004. Основной slippage=0.0005;
единственный stress-case — удвоенное slippage=0.001 на тех же данных.
Три синтетических ряда по 1440 точек: постоянная цена 100, синус 100±2 с
периодом 120 минут, монотонный рост 100→200. Их формулы находятся в runner.
Во время replay внешняя сеть запрещена; источники/параметры не подменялись
ради доходности. Subclass-наблюдатели только сохраняли состояния и суммы издержек.

результатов, а не PASS экономики. Независимая terminal mark из JSON —
диагностика расхождения рычагов, не восстановленный достоверный Net: история
уже содержит неверные переходы. Комиссии учтены движком; повторно их из

24-месячный тест, независимые последние 6 месяцев и допуск по PF/DD **не
подтверждены**. Продолжать квалификационные исследования на этом движке до
устранения подтверждённых дефектов бессодержательно. BSXperpA NET-FLOOR из
t-invest также не прогонялся: это другой репозиторий и другие входы; ни PASS,
ни изменение закреплённого порога здесь не заявляются.

проверены login, overview, ticker, history, logs и settings на localhost со

в `screenshots/`; ошибки карточки — также в ticker_console.json.

- Anonymous `/api/overview`: 302 на login. Страницы overview/history/settings/logs:
  HTTP 200; логи фикстуры читаются. Это ограниченный PASS отображения оболочки.

  попытку target=all: она пропускается. Нельзя считать UI подтверждение
  серверным ограничением области управления.
- Поздняя версия мониторинга не подключена к Ledger и не показывает liabilities,
