## Источник и артефакты

Источник — официальные Binance USD-M archives: [контракт Binance Public Data](https://github.com/binance/binance-public-data). По документации Binance эти klines получены из `/fapi/v1/klines`. Для массовой загрузки использованы monthly July/August/September и daily October 1–23. Полный июльский raw ZIP содержит также даты до начала целевого периода; нормализованный набор строго обрезан по указанным границам.

Каталог: `data/intraday_90d_20260726_20261024/`.

| Путь внутри каталога | Содержимое |
|---|---|
| `raw/{symbol}/` | Исходные ZIP и опубликованные `.CHECKSUM`, без извлечения поверх рабочих данных |
| `candles/{symbol}_live.feather` | Нормализованные свечи с `time` в UTC, исходными open/close time и дополнительными полями объёма/сделок |
| `symbols/{symbol}.json` | URL, период, статусы источников, SHA256, покрытие каждого символа |
| `manifest.json` | Зафиксированная вселенная, границы, source contract, hash загрузчика и результаты |
| `coverage_utc_sessions.csv` | Матрица 154×90: в каждой ячейке 1440 свечей |
| `quality.csv` | Строки, пропуски, нулевые объёмы, границы, hash по символам |
| `verification.json` | Результат независимой проверки |
| `SHA256.json` | Hashes исходных ZIP, symbol metadata и итоговых feather |

Исходные timestamps сохранены в миллисекундах; `time` выведен из open_time, не из mtime. Независимая проверка подтверждает их взаимное соответствие, границы минут и close_time=open_time+59999. Также проверены конечность OHLCV, положительность цен, неотрицательный volume и OHLC-инварианты.

Код загрузки: `scripts/download_intraday_90d.py`; независимая проверка: `reports/verify_intraday_90d.py`. Существующие загрузчики, терявшие time, в этой загрузке не использовались. Новые зависимости не устанавливались. Каталог данных исключён из Git текущим правилом `.gitignore`; локальные артефакты следует сохранять отдельно.

## Что это разрешает по плану

Новый набор устраняет технический блокер отсутствия подтверждённого синхронного времени для выбранных 154 символов. Это не доказательство прибыльности и не подтверждение происхождения старого sweep.

Перед причинным replay остаются D1–D3: граница сессии и перенос/закрытие; общий капитал, paper/active slots и margin mode; допустимые потери/MaxDD/exposure. D5 решён для источника, вселенной и загрузки 90 дней, но бюджет экспериментов не задан.

Для исторического scanner с 24-часовым объёмом нужен прогрев: не считать первый день доступным для полного 24h ranking без предшествующих данных. История до начала окна есть в raw July archive, но правила её использования для прогрева должны быть явно зафиксированы при replay, а не добавлены молча в число тестовых сессий.

Также ещё не проверены исторический полный состав биржевого рынка, funding receipts, mark price, maintenance tiers, реальные contract filters и исполнимость. Текущая вселенная фиксирована по прежнему набору пользователя; она не объявляется полной point-in-time вселенной Binance.

Бэктесты стратегии на новой 90-дневной истории, подбор параметров, запуск supervisor/ботов и выделение реального капитала не выполнялись. После отчёта — остановка перед следующим этапом.
