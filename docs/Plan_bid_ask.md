3. Реализуй оценку

Принятая политика:
- LONG оценивается по best bid;
- SHORT оценивается по best ask;
- стоимость доли сохраняет существующую модель «базовая стоимость + unrealized P&L»;
- CASH и фиксированная USDT-стоимость VIRTUAL сохраняют действующие правила;
- новая оценка используется для стоимости портфеля, текущих весов и решений ребалансировки, а не только для дашборда.

Для линейных контрактов:
- LONG unrealized P&L = abs(quantity) × (bid − entry_price);
- SHORT unrealized P&L = abs(quantity) × (entry_price − ask).

Сохрани существующие множители контрактов, единицы измерения и правила учёта. Если модель проекта отличается от этих предпосылок, останови зависимую часть и задай конкретный вопрос.
